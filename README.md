## WordPress需要服务器吗？先分清三种用法

自建公开站点需要服务器，托管服务不需要你买服务器，本地测试也不需要。三种情况常被混在一起，所以越查越乱。

- **自建 WordPress**：从 WordPress.org 下载程序，装在自己的主机或云服务器上。程序要运行，数据库要存内容，图片要占空间，这些都得由服务器提供。
- **托管 WordPress**：WordPress.com 这类服务把运行环境包好了，你注册账号就能写文章，不用管服务器、PHP 和数据库。代价是可控程度不同，插件、主题和导出限制要看具体方案。
- **本地测试**：在自己电脑上装一个本地环境，用来学主题、改插件、试排版。网站只有你自己能访问，不需要买服务器。

如果你要做的是企业官网、博客、商城，基本都落在第一种。下面继续按自建讲。

## 自建 WordPress，服务器到底在干什么？

服务器负责运行 PHP、存放 MySQL/MariaDB 数据库、保存图片附件，并把页面发给访客。没有这层运行环境，WordPress 只是一堆文件，别人打不开。

具体一点：访客打开你的域名时，请求会先到服务器，服务器再让 PHP 执行 WordPress 程序，从数据库里取出文章和设置，最后把 HTML 页面返回给浏览器。图片、插件、主题文件也都在服务器上。所谓“买服务器”，买的是计算、内存、硬盘、带宽和公网 IP，不是买 WordPress 软件本身。WordPress 软件是免费的。

配置上，1核1G 能跑一个演示站，但装几个插件、开 WooCommerce 后台、传一批高清图，就容易出现后台卡、保存慢。个人博客和小官网从 2核2G 起步更稳；要做商城、会员、多人编辑，内存和带宽都要往上加。

## 买服务器前，先确认这4件事

先确认四件事：是否要备案、服务器能不能装 WordPress、带宽和流量够不够、备份怎么做。任何一项没确认，便宜机器也可能变成麻烦。

1. **备案**：在中国大陆节点对公网提供网站服务，通常要走 ICP 备案；香港或海外节点一般不用备案，但面向大陆用户的访问速度和合规要自己权衡。
2. **环境**：WordPress 需要 PHP 和 MySQL/MariaDB。买之前看是否提供 WordPress 应用镜像、控制面板或一键部署，别等买完才发现要自己编译环境。
3. **带宽和流量**：个人博客以文字为主，3M 左右起步够用；图片站、WooCommerce 后台、订单页更吃资源，别只盯着 CPU 和内存。
4. **备份**：问清楚快照是否免费、保留几天、数据库能不能单独恢复。没有备份的便宜服务器，出一次事就可能把省下的钱赔回去。

## 什么情况下不用买服务器？

用 WordPress.com 这类托管服务、只在本地学习测试，或者做纯静态网站，都不需要自己买服务器。你要的是“能写文章、能上线”，不是“必须拥有一台云服务器”。

反过来，如果你要装自己的主题和插件、改代码、做 WooCommerce、接统计和邮件服务，自建 WordPress 的自由度更高，服务器这笔钱基本省不掉。省的方向应该是选对配置和计费周期，而不是找一台随时会挂的免费主机。

## 常见问题

**WordPress 软件免费，为什么建站还要花钱？**
因为免费的是程序本身，域名、服务器、主题、插件和备份服务都要成本。你可以用免费主题和免费插件压低预算，但域名和主机通常省不了。

**1核1G 能跑 WordPress 吗？**
能跑，但不适合长期正经运营。装几个插件、传高清图、开 WooCommerce 后台就容易卡。个人站建议 2核2G 起步，商城和会员站直接看 2核4G 以上。

**云服务器和虚拟主机选哪个？**
只想写博客、装少量插件，虚拟主机或轻量云服务器够用；要自定义环境、装商城、加缓存和队列，云服务器更合适，但备份和安全要自己管。

**国内服务器一定要备案吗？**
在中国大陆境内对公网提供网站服务，通常需要 ICP 备案。用香港或海外节点一般不用备案，但大陆访问速度和合规问题要自己评估。

**腾讯云活动价能续费同价吗？**
不一定。活动价、首购价和续费价是不同概念，下单前看活动规则和续费价格，别只看第一行大字。
